# OAuth 应用配置常见问题

## 问题：无法查看智能体

### 错误信息
```
无法查看智能体
请检查你的网址或加入对应工作空间后重试
```

### 原因分析

这个错误表示 OAuth 应用没有权限访问指定的智能体（Bot）。

### 解决方案

#### 方案一：创建自己的 OAuth 应用（推荐）

1. **访问扣子开放平台**
   https://www.coze.cn/open/oauth/apps

2. **创建 OAuth 应用**
   - 点击「创建 OAuth 应用」
   - 应用类型：**移动端/PC 桌面端/单页面应用**
   - 应用名称：随意

3. **配置回调地址**
   ```
   https://aiduanju.coze.site/api/auth/oauth/coze/callback
   ```

4. **⚠️ 关键步骤：添加智能体权限**
   
   方式 A - 设置应用为公开：
   - 在应用详情页找到「可见范围」或「权限配置」
   - 选择「公开」或「所有人可见」
   
   方式 B - 添加智能体：
   - 在应用详情页找到「智能体管理」
   - 添加需要访问的智能体 ID

5. **使用自己的应用 ID**
   - 复制你创建的应用 ID
   - 在个人中心绑定页面输入该 ID

#### 方案二：加入智能体工作空间

如果你使用的是他人创建的 OAuth 应用：

1. 联系智能体所有者
2. 请求将你的扣子账号添加到工作空间
3. 或请求将智能体添加到 OAuth 应用的可见范围

### 为什么会出现这个问题？

OAuth 应用的权限模型：

```
OAuth 应用
    ↓ 授权访问
智能体（Bot）
    ↓ 需要权限
用户才能调用
```

如果 OAuth 应用没有智能体的访问权限，即使用户授权了，也无法调用智能体。

### 最佳实践

1. **创建自己的 OAuth 应用**：最安全、最可控
2. **设置应用为公开**：适用于公开服务
3. **使用系统级 OAuth**：适用于团队内部使用（需要管理员配置）

### 验证配置是否正确

1. 打开 https://www.coze.cn/open/oauth/apps
2. 进入你的 OAuth 应用详情
3. 检查「可见范围」是否包含目标智能体
4. 检查「回调地址」是否配置正确
