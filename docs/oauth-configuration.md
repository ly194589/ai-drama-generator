# 扣子平台 OAuth 配置指南

## 快速开始

### 方式一：移动端/PC 桌面端/单页面应用（推荐）

**特点**：无需 Client Secret，配置最简单

1. 访问 [扣子开放平台](https://www.coze.cn/open/oauth/apps)
2. 创建 OAuth 应用，选择 **"移动端/PC 桌面端/单页面应用"**
3. 添加回调地址（系统会自动显示）
4. 复制 **应用 ID**（这就是 Client ID）
5. 在登录页面输入应用 ID 即可登录

**示例**：
```
应用 ID: 1139389246544
应用类型: 移动端/PC 桌面端/单页面应用
→ 无需 Client Secret，直接登录
```

### 方式二：Web 后端应用

**特点**：需要 Client Secret，适合服务端应用

1. 访问 [扣子开放平台](https://www.coze.cn/open/oauth/apps)
2. 创建 OAuth 应用，选择 **"Web 后端应用"**
3. 添加回调地址
4. 复制 **Client ID** 和 **Client Secret**
5. 在登录页面输入凭证登录

---

## 详细步骤

### 步骤 1：创建 OAuth 应用

访问 https://www.coze.cn/open/oauth/apps，点击「创建 OAuth 应用」：

| 字段 | 填写内容 |
|------|----------|
| 应用名称 | AI短剧生成器（任意） |
| 应用类型 | 普通 |
| 客户端类型 | **移动端/PC 桌面端/单页面应用**（推荐） |

### 步骤 2：配置回调地址

在应用详情页添加回调地址：

```
{您的访问域名}/api/auth/oauth/coze/callback
```

系统会在配置页面自动显示完整的回调地址，直接复制即可。

### 步骤 3：登录

1. 返回 AI 短剧生成器
2. 点击「扣子账号登录」
3. 输入应用 ID
4. 选择正确的应用类型
5. 完成授权

## 两种应用类型对比

| 特性 | 移动端/PC 桌面端/单页面应用 | Web 后端应用 |
|-----|--------------------------|-------------|
| 授权方式 | PKCE | 授权码 |
| Client Secret | ❌ 不需要 | ✅ 需要 |
| 安全性 | 高（动态密钥） | 高（固定密钥） |
| 配置复杂度 | 简单 | 较复杂 |
| **推荐度** | ⭐⭐⭐⭐⭐ | ⭐⭐⭐ |

## 常见问题

### Q: 为什么推荐选择"移动端/PC 桌面端/单页面应用"？

1. **无需 Client Secret**：更安全，不需要管理密钥
2. **配置更简单**：只需要复制应用 ID
3. **安全性更高**：每次登录使用动态生成的密钥

### Q: 登录时提示"无法查看智能体"？

**原因**：您使用的是他人创建的 OAuth 应用

**解决方案**：创建自己的 OAuth 应用，使用自己的应用 ID

### Q: 授权后跳转失败？

**检查项**：
1. 回调地址是否配置正确
2. 回调地址是否包含正确的域名和路径
3. 是否添加了回调地址到应用配置中

### Q: PKCE 模式的原理是什么？

PKCE（Proof Key for Code Exchange）流程：
1. 系统生成随机 `code_verifier`
2. 计算 `code_challenge = SHA256(code_verifier)`
3. 授权请求携带 `code_challenge`
4. 获取 token 时携带 `code_verifier` 验证身份

这样即使授权码被截获，没有 `code_verifier` 也无法换取 token。
